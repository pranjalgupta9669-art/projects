# projects
JALA Academy: Python & SQL Mastery
This repository contains a structured collection of programming exercises and database queries designed to build a strong foundation in Python Programming and Relational Database Management (SQL).

📂 Project Structure
jala_academy.py: A comprehensive Python script covering basics, OOP, Exception handling, and File I/O.

sql_assignment.sql: A database script containing table schemas, data insertion, and 89 practical SQL queries.

🐍 Python Implementation
The Python script is organized into modules to demonstrate specific language features:

1. Core Basics & Syntax
Basics: Print operations, data types (int, boolean, float), and variable scope.

Operators: Arithmetic, relational, and logical operations.

Loops: Iteration using for and while loops, including range-based logic.

2. Data Structures & Logic
Arrays/Lists: Calculating sums, averages, and finding duplicate values.

Dictionaries: Nested dictionary structures, adding/updating keys, and deletion.

Strings: Concatenation, length checking, and substring replacement.

3. Object-Oriented Programming (OOP)
Inheritance: Demonstrates multi-level inheritance and method overriding.

Constructors: Simulating multiple constructors using default arguments.

Abstraction: Using the abc module to define abstract base classes.

Access Modifiers: Implementation of private fields and methods using double underscores.

4. Advanced Concepts
Exception Handling: Custom exception classes, try-except-finally blocks, and specific error catching (e.g., ZeroDivisionError).

File I/O: Reading/writing text files and using seek() for specific index reading.

🗄️ SQL Assignments
The SQL script manages a sales database with three primary tables: salespeople, cust (customers), and orders.

Key Query Categories:
Basic Filtering: Using WHERE, IN, BETWEEN, and REGEXP.

Aggregations: Calculating MAX, MIN, SUM, and AVG grouped by specific attributes.

Joins: Complex relational queries using INNER JOIN, LEFT JOIN, and SELF JOIN.

Subqueries: Utilizing EXISTS, ANY, and ALL for nested logic.

Data Formatting: Using CONCAT and DATE_FORMAT to generate readable reports.
